# Rain Compatibility Tools

日本語 | [English](README.en.md)

Android 17上でRainを起動・開き直した際に起こる不定期クラッシュの調査と、特定のリソース生成失敗への限定的な補修を行うRootアプリです。**すべてのクラッシュを修正できたわけではありません。**

## 対応範囲

- Rain `dev.raincord.app` 344.13 Stable（344013）。インストール済みAPKのSHA-256も照合します。
- Android 17 / SDK 37、メインユーザー。Rootが必要です。
- Rain内蔵のLSPatchをそのまま利用します。外部VectorからRainへ重ねて注入しないでください。二重注入による起動クラッシュを実機で確認しています。

## 使い方

1. APKをインストールし、このアプリのRootを許可します。
2. 「画面リソースの生成失敗を補修する」をONにします。
3. Rainの次の自然な起動から反映されます。Rainを強制終了したり、端末を再起動したりする必要はありません。
4. 不具合が起きた後、このアプリの「診断イベントを読み込む」で記録を確認できます。

アンインストールする場合は、先にOFFにするかRainのキャッシュを消去してください。

OFFにすると、Rain本体から取り出した元のモジュールキャッシュへ復元します。OFFも次回の自然な起動から反映されます。Rainのキャッシュを消去すると補修も消えるため、必要なら再適用してください。

## 変更するもの

Rainが展開する `cache/lspatch/dev.raincord.xposed/3404327306.apk` に、このプロジェクトの小さなKotlinフックを追加します。適用前に本体APK・埋め込みモジュール・現在のキャッシュのハッシュと所有者を確認し、完成したファイルをatomic renameで入れ替えます。未知の変更があるキャッシュは上書きしません。

インストール済みのRain本体APK、ログイン情報、メッセージ、システムサービスは変更しません。常駐サービスや定期ポーリングもありません。

## 補修と診断

画面のContextを生成中、AndroidがResourcesを返せなかった場合だけ、**同じ引数・同じAndroidメソッドを一度だけ**呼び直します。正常な結果を差し替えたり、例外を成功扱いにしたり、システム共通のResourcesで代用したりしません。

診断はRainの内部データ `files/raincompat/` に保存します。起動段階、リソースの再試行結果、Androidが記録した前回の終了理由・終了コード・時刻・PIDだけを記録し、メッセージ、トークン、画面、音声、スタック本文は保存しません。現在分32KBと前回分32KBでローテーションします。

## 現在の限界

- 元の不定期クラッシュは毎回再現せず、長時間の利用での改善率は未確認です。
- 過去に観測したLSPatch / ARTのネイティブクラッシュを、このJavaリソース補修で修正したとは主張しません。
- Rootでの適用・復元と診断表示のUIを含め、端末やRainの全バージョンに対応するものではありません。
- 配布物にRain本体や同アプリのモジュールは含めません。自分でインストール済みの対応版から、端末上でキャッシュを生成します。
